# Publication scope

This repository shares an experimental skill and its development evidence under MIT. It does not certify production readiness or token savings.

The owner approved the public repository and MIT notice for tamaraw01. The runtime remains v0.2.1, matching the corrected trial. Documentation and evidence packaging do not change the tested procedure.

Before claiming production readiness, complete held-out paired trials, independent quality review, host installation checks, and trustworthy whole-task usage accounting. Local Python checks do not prove all platforms in the CI matrix passed.
